# Rhodium Germany — External Proof

Public, sanitized evidence for Rhodium Germany external execution and reproducible proof workflows.

This repository is part of the public Rhodium Germany evidence surface. It is intended to show measured outputs without exposing the protected research/core architecture.

## Principles

- measured results only
- cryptographic integrity where available
- scope limitations remain attached to the result
- no private keys, credentials, customer secrets or protected core logic
- no claim of universal superiority from a test that does not support it
